## Part 3️⃣: 采样策略设计

### 🎯 核心问题诊断

**模型的虚假特征学习**:

```
当前模型规则 (错误):
├─ Human = 口语化 + 有缺陷 + 短
├─ AI = 正式 + 流畅 + 长
└─ 结果: 口语/缺陷的AI被识为Human, 正式的Human被识为AI

真实应该学习 (正确):
├─ Human = 自然思考过程 + 上下文连贯 + 个人风格
├─ AI = 生成模式 + 提示词残留 + 统计规律
└─ 结果: 泛化能力强, 难以绕过
```

### 📌 三层采样策略

#### 层1️⃣: 口语AI样本生成 (2,000条)

**目标**: 打破"缺陷=Human"的假设

**特征**:
- 长度: 120-200字 (短)
- 语法错误: 5-10处/篇 (有)
- 连接词: 然后、其实、就是 (口语)
- 完整度: 70-80% (不完美)

**生成配置**:
```json
{
  "models": ["gpt-4-turbo", "glm-4", "deepseek-v3"],
  "temperatures": [0.9, 0.8, 0.85],
  "prompt": "用很口语的、不正式的、有点错误的语气回答：{topic}",
  "max_tokens": 200,
  "post_processing": {
    "inject_typos": "10-20%",
    "remove_sentences": "5-10%",
    "colloquial_replacement": "20-30%"
  }
}
```

**实现方式**:
1. 直接要求模型生成口语版本
2. 随机注入语法错误
3. 随机删除部分句子
4. 替换正式词汇为口语词

#### 层2️⃣: 缺陷AI样本生成 (1,000条)

**目标**: 让模型学习AI也会"犯错"

**特征**:
- 长度: 80-150字 (极短)
- 完整性: 50-70% (不完整)
- 重复率: 20-40% (频繁重复)
- 逻辑: 混乱、无序

**三种生成策略**:

```
策略A: 早期截断 (400条)
  └─ 在40-50%位置硬停，只输出前半部分

策略B: 低质量提示词 (300条)
  └─ 诱发重复：如"重复说出关键词"

策略C: 极端参数 (300条)
  └─ top_p=0.3 (限制多样性)
  └─ frequency_penalty=2.0 (惩罚重复)
```

#### 层3️⃣: 正式Human样本补充 (2,000条)

**目标**: 打破"完美=AI"的假设

**四大来源**:

```
知乎高赞回答:      800条
  └─ 筛选: 赞数>100, 字数>300
  └─ 特征: 专业、严谨、有参考资料

学术文章摘要:      600条
  └─ 来源: arXiv, 知网, 维普
  └─ 特征: 学术术语、严密逻辑

新闻/评论:         400条
  └─ 媒体: 人民日报、新华社、财经类
  └─ 特征: 权威、完整、流畅

官方文档:          200条
  └─ 政府公告、产品说明、学术指南
  └─ 特征: 规范、系统、完美
```
