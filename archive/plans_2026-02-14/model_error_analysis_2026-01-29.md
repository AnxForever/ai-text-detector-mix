# 模型错误分析与改进方案

> 更新时间: 2026-01-29 14:23
> 模型: bert_v2_balanced

## 一、错误类型总结

### 1.1 误判为AI的Human文本 (详细测试)

| 错误类型 | 示例 | AI概率 | 严重程度 |
|---------|------|--------|---------|
| **温馨提示类** | "温馨提示：疫情期间请佩戴口罩，保持社交距离" | 100% | 🔴 严重 |
| **紧急通知类** | "紧急通知：因暴雨预警，今日下午课程取消" | 100% | 🔴 严重 |
| **日常叙事类** | "今天天气真好，适合出去走走" | 100% | 🔴 严重 |
| **简短确认类** | "好的，没问题，我知道了" | 100% | 🔴 严重 |
| **正面评价类** | "用了一个星期，感觉还不错，物流也很快，好评" | 100% | 🔴 严重 |
| **生活分享类** | "周末去爬山，累死了但是风景很美" | 97.5% | 🟡 中等 |
| **新闻报道类** | LCSTS新闻样本 | 18.6%误判 | 🟡 中等 |

### 1.2 正确识别的Human文本特征

✅ 招聘信息 (0% AI概率)
✅ 商品描述 (0% AI概率)  
✅ 带疑问的短消息 (0% AI概率)
✅ 带负面评价的文本 (0.1% AI概率)

### 1.3 关键发现

**模型错误地学习了以下规则**:
- "语气积极正面" → AI
- "句子完整通顺" → AI
- "表达礼貌客气" → AI

**实际应该区分的是语义特征，而非情感/礼貌程度**

### 1.2 正确识别的Human文本特征

- 口语化、非正式
- 带有网络流行语 (yyds, 绝绝子, 无语子)
- 情绪化表达 (救命, 笑死)
- 不完整句子
- 带有错别字或语病

## 二、根因分析

### 2.1 训练数据Human样本来源

| 来源 | 数量 | 占比 | 特点 |
|------|------|------|------|
| core_v1 | 14,658 | 50.9% | 知乎问答为主 |
| HC3-Chinese | 8,121 | 28.2% | 问答对话 |
| M4-qazh | 3,141 | 10.9% | 问答 |
| LCSTS | 2,739 | 9.5% | 新闻摘要 |
| VCSum | 150 | 0.5% | 会议摘要 |

**问题**: Human样本主要来自**问答类**数据集，缺少：
- 正式通知/公告
- 商业文案/广告
- 产品评价
- 日常短消息
- 社交媒体帖子

### 2.2 Human样本特征分布

| 特征 | 占比 | 问题 |
|------|------|------|
| 正式文本(通知/公告) | 6.3% | **严重不足** |
| 新闻类 | 19.4% | 偏少 |
| 问答风格 | 10.3% | 过多 |
| 带列表结构 | 27.1% | 正常 |

### 2.3 核心问题

**模型学到了错误的特征**:
- "写得通顺、结构完整" → AI
- "口语化、不完整" → Human

**实际应该是**:
- AI和Human都可以写出通顺的文本
- 区分点应该是语义特征，而非表面形式

## 三、改进方案

### 3.1 核心问题

模型把"写得好/积极正面"当成AI特征，需要：
1. 补充"写得好的Human"样本
2. 补充"口语化的AI"样本
3. 打破表面特征关联

### 3.2 Human样本补充计划

#### 需要补充的类型 (高优先级)

| 类型 | 特征 | 目标数量 | 来源 |
|------|------|---------|------|
| 温馨提示 | 礼貌、正面 | 1,000 | 手动收集 |
| 日常分享 | 完整叙事、积极 | 2,000 | 微博/小红书 |
| 正面评价 | 好评、推荐 | 2,000 | 电商评价 |
| 简短确认 | 礼貌回复 | 500 | 手动构建 |
| 新闻报道 | 正式、完整 | 3,000 | LCSTS/THUCNews |

#### 数据来源优先级

1. **LCSTS** - 已提取5000条，18.6%误判，需要加入训练
2. **微博数据** - 日常分享类
3. **电商评价** - 正面评价类
4. **手动构建** - 温馨提示、简短确认

### 3.3 AI样本调整

需要生成更多"口语化AI"样本：
- 模仿人类日常分享风格
- 减少"首先、其次、综上所述"等典型AI词汇
- 增加不完整句子、口语化表达

### 3.4 立即执行

```bash
# 1. 将LCSTS样本加入训练集
cat datasets/human_formal_samples.jsonl >> datasets/bert_v2_overnight/human_supplement.jsonl

# 2. 重新平衡训练集
python scripts/data_cleaning/balance_with_supplement.py

# 3. 重新训练
python scripts/training/train_balanced.py --supplement human_supplement.jsonl
```
