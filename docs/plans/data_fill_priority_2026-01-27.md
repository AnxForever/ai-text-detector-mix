# 数据补齐优先级清单（场景版，待统计）

> 更新时间: 2026-01-27
> 说明: 该清单作为“场景驱动”版本的优先级规则，待场景标签补全与桶统计后填入具体缺口数。

---

## 1. 优先级规则

- **P0（必须优先）**: 各场景内的列表要点式 / 说明书式（200–1000 字）不足 35% 的桶
- **P1（并行补齐）**: 报告总结式 / 连续解释式占比不足的场景
- **P2（低优先）**: 对话式与混合格式（仅用于均衡）

---

## 2. 目标桶（先行标准）

在每个场景内部，优先补齐以下桶（以“每桶 200”为基础线，实际由统计决定）：
- list / guide × 200-500 / 500-1000
- list / guide × 1000-2000（学业写作/职场写作/消费内容优先）
