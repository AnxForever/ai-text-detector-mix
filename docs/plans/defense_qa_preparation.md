## V7 模型强弱速查

### 擅长（安全演示区）

| 类型 | 原因 | 建议文本 |
|------|------|---------|
| 标准AI解释性文本 | 训练数据充足 | 百科解释、知识科普 |
| HC3风格问答 | HC3占人类样本61.7% | 知乎风格问答 |
| 新闻报道 | thucnews+头条~7800条 | 标准新闻稿 |
| 口语化Human文本 | 最大类别37,427条 | 日常闲聊、吐槽 |
| 中等长度(200-1000字) | 训练数据密集区间 | - |
| 多模型AI文本 | 覆盖9+模型 | GPT-4/DeepSeek/Kimi等 |

### 不擅长（避开雷区）

| 类型 | 根因 | 风险 |
|------|------|------|
| AI技术文档 | 技术类92.9%是AI | 99%置信度误判为Human |
| 正式人类文本(通知/公告) | 人类样本缺少正式文本 | 100%误判为AI |
| 口语化AI文本 | AI训练数据太正式 | 误判为Human |
| 极短文本(<100字) | 信息量不足 | 判断不稳定 |
| 极长文本(>1000字) | AI/Human长度偏差 | 倾向判AI |
| 代码讲解 | 人类样本仅809条 | 人写教程判AI |
| 文化/艺术/法律 | 人类样本极少 | 人类文本误判 |

### 一句话记忆

> **安全区 = 口语人类文 + 正经AI文 + 中等长度 + 非技术主题**
> **危险区 = 正经人类文 + 口语AI文 + 极端长度 + 技术/编程主题**

## Q1: "准确率98.71%可信吗？会不会过拟合？"

98.71%在独立测试集(6,601条)上得出，训练/验证/测试严格划分。但存在高估：

1. **长度偏差**：AI均值965字 vs Human 413字(2.34:1)，模型可能利用长度捷径
2. **分布偏差**：测试集与训练集同源，未做跨域(OOD)测试

V7引入长度感知损失(length penalty=0.1)缓解。保守估计真实泛化准确率约90-95%。

## Q2: "模型学到'正式=AI, 口语=Human'，不就是学错了？"

是的，这是核心发现。根因：

- 人类样本61.7%来自HC3问答(口语化)
- AI样本以正式文本为主(口语标记仅0.10/篇)

改进思路：补充正式Human文本+口语化AI文本，打破虚假关联。DeTeCtive(NeurIPS 2024)提出多层次对比学习捕获更深层风格特征。

## Q3: "[SEP]标记机制原理？推理时没标记怎么办？"

**原理**：训练时在人类/AI边界插入`[SEP]`，两个作用：
1. 显式分段：告诉模型"这里发生风格转换"
2. 注意力引导：BERT对[SEP]有天然跨段注意力

**效果**：C2检测79.8%→93.84%，提升14%

**推理**：双层架构解决——分类器先判整体，边界检测器逐token标注定位。Token准确率96.69%，实际误差0-8字符。

## Q4: "为什么选BERT不选GPT/LLaMA？"

1. **任务适配**：分类任务，BERT双向编码器优于自回归模型
2. **部署效率**：~390MB，适合实际部署，学生项目算力有限
3. **前沿验证**：2025年研究表明RoBERTa-based检测器仍是强基线

## Q5: "能检测所有AI模型吗？新模型怎么办？"

覆盖9+主流模型(GPT-4/DeepSeek/Llama/GLM等)。对未见新模型会下降。

应对：
- DeTeCtive的TFIA可不重训练适应新模型
- 多温度采样(0.2+0.7各50%)增加多样性覆盖
- 持续学习管道增量更新

## Q6: "66,001条数据够吗？质量怎么保证？"

来源：公开数据集(HC3/LCSTS/M4) + 核心自建(core_v1 14,658条) + 增量生成(generated_v2 11,116条)

质量保证：
- 清洗管道：移除过短/重复/模板文本
- 禁用词/提示词残留检测(18.8%)
- 标签50:50完美平衡

## Q7: "边界检测49.51%不是很低吗？"

49.51%是±5 tokens严格匹配率。Token级准确率96.69%。实际演示误差0/1/8字符。

边界附近风格变化是渐进的而非突变的，即使人类专家也难精确到单个token。

## Q8: "实际应用价值？已有很多检测工具了"

1. **中文专精**：现有工具(GPTZero等)主要针对英文
2. **混合文本检测**：不只判全文，检测"人写一部分+AI续写"的混合情况
3. **边界定位**：精确定位AI生成起止位置
4. **轻量部署**：390MB，FastAPI服务，普通服务器可运行

## Q9: "项目局限性？"

1. 虚假特征学习：部分依赖长度/形式特征
2. 领域泛化有限：训练以问答类为主
3. 对抗鲁棒性未测试
4. 单语言(仅中文)

已有改进计划：三层采样策略+对比学习方法。

## Q10: "AI进化了模型还能用吗？"

军备竞赛本质。应对方向：
1. 多层次对比学习(DeTeCtive)学习深层风格特征
2. 水印方案从生成端入手
3. 持续学习管道增量更新

检测系统提供参考信号而非绝对判定，就有应用价值。
