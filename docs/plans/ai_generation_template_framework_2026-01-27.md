# AI 生成模板框架（按场景 × 文风 × 长度）
> 生成时间: 2026-01-27
> 目标: 生成 AI 样本以补齐场景配额与文风配比（主训练集 60K）。
> 备注: 仅定义模板与约束，不实际生成数据（待 API 可用后执行）。
> 补充: 2026-01-28 生成可落库模板（含 MUST/NICE 约束），并将 2000+ 长度映射为 1000-2000。
> 参见: docs/plans/ai_generation_templates_v2_mapped_2026-01-28.yaml

---

## 1. 统一元数据字段（每条样本必记录）
- y_main: AI
- scenario / scenario_id
- style / length_bucket
- model_family / model_name / model_version
- prompt_id
- decoding（temperature/top_p/max_tokens）
- seed（如有）
- created_at
- source_type: ai_generated
- constraints_version: v2

---

## 2. 全局硬约束（适用于所有模板）

**禁止项**
- 禁止自我指代（如“作为 AI…”）
- 禁止拒绝/免责声明
- 禁止空泛建议（“建议搜索/咨询客服”）

**强制项**
- 直接输出正文内容，不加“解释为何这样写”
- 包含具体细节（参数/阈值/版本号/条目要点）
- 保持结构化写作（列表/小节/表格）

---

## 3. 长度控制策略

| length_bucket | 目标范围（中文字符） | 模板提示建议 |
| --- | --- | --- |
| 200-500 | 260–520 | 2–4 段 / 6–12 条要点 / 1 小表 |
| 500-1000 | 600–1000 | 4–8 段 / 12–24 条要点 / 1–2 表 |
| 1000-2000 | 1200–1800 | 6–12 段 / 20–40 条要点 / 2–3 表 |

---

## 4. 解码配置（每个 prompt_id 至少两组）

- 保守版（规范文案）：temperature 0.2 / top_p 0.9
- 发散版（多样化）：temperature 0.7 / top_p 0.95
- 改写版（可选）：先生成，再要求“换一种说法但保持结构”

---

## 5. 场景模板库（示例）

## 6. 生成后质检

- 检查禁用口癖/拒绝句
- 检查结构化要素是否存在（列表/小节/表格）
- 检查长度落桶
- 先去口癖/去重再入库
- 混合文本不进入主训练集
