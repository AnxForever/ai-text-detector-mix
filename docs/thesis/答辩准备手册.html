2. 算法与模型关键点

2.1 基础模型：BERT-base-chinese

参数 值
隐藏层维度 768
注意力头数 12
编码层数 12
最大位置编码 512
词表大小 21,128
总参数量 ~110M

选型依据：双向编码器对判别任务优于单向解码器（GPT类）；与 RoBERTa-wwm 性能相当但开源社区支持更完整。

2.2 双层检测架构

输入文本
    │
    ▼
┌─────────────────────────────────────┐
│  第一层：文档级分类器                  │
│  BertForSequenceClassification      │
│  [CLS] → 分类头 → Human/AI + 置信度  │
└─────────────────────────────────────┘
    │
    ├── 输出 "human" 或 "ai" → 直接返回
    │
    └── 输出 "mixed" → 进入第二层
            │
            ▼
┌─────────────────────────────────────┐
│  第二层：Token级边界检测器            │
│  BertForTokenClassification         │
│  每个token → Human(0)/AI(1) 标签     │
└─────────────────────────────────────┘
            │
            ▼
        边界位置 + 逐句分类结果

理论基础：Viola & Jones (2001) 级联分类器思想 — 快速粗粒度筛选 + 精细处理困难样本。

2.3 Temperature Scaling 校准

问题：深度神经网络普遍存在过度自信现象（Guo et al., 2017）。

公式：$P(y=c|x) = \frac{exp(z_c/T)}{\sum_k exp(z_k/T)}$

  • T=1：标准 Softmax
  • T>1：分布更平滑（降低自信度）

校准效果：

指标 校准前 (T=1) 校准后 (T=0.8165) 改善
ECE 0.0168 0.0034 -79.8%
Accuracy 98.69% 98.69% 不变

优势：只引入单个参数 T，不改变预测结果（argmax不变），只改善置信度可靠性。

2.4 训练策略

损失函数 — 长度感知标签平滑损失（LA-LSL）： - Label Smoothing (ε=0.05)：防止模型过度自信 - 长度感知权重：$w = 1/(1+0.1 \times |log(L/500)|)$，防止捷径学习

采样策略 — 双维度加权采样：同时平衡标签维度（Human/AI）和长度维度（6个长度桶）

优化配置：

参数 值
优化器 AdamW
学习率 1e-5
batch_size 8（梯度累积4步，有效batch=32）
max_length 256
epochs 4（Early Stopping，最佳 Epoch 2）
warmup_steps 500
label_smoothing 0.05

6. 结论

6.1 系统优势

  1. 整体性能领先，召回率最高 — 98.69% 准确率、99.28% 召回率
  2. 长度不变性 — 所有长度区间均达 100% 准确率，性能方差 0.0
  3. 格式鲁棒性 — 格式对抗测试最大下降仅 0.05%
  4. 混合文本检测能力 — C2续写 93.84%，C3改写 100%，边界误差 0-8 字符
  5. 概率校准可靠 — ECE 从 0.0168 降至 0.0034（-79.8%）
  6. 部署效率友好 — 127.4 样本/秒，7.8ms 延迟，672MB 显存
  7. 跨模型泛化 — 独立评估集含训练未见模型，准确率 98.57%

6.2 三大创新点

创新点 1：基于 BERT 微调的中文 AI 文本二分类方法 - 融合 Length-Aware Label Smoothing Loss + 双维度加权采样 + Temperature Scaling 校准 - 2,599 条无泄露评估集：98.69% 准确率、99.28% 召回率、97.75% F1

创新点 2：Data-Centric AI 数据治理流水线 - V10→V11a→V11b→V11c 四阶段治理（控制变量设计） - 标签噪声清洗 + 弱域增补 + 长文边界修复 - 独立评估集准确率 97.69% → 98.57%（+0.88%），总错误 21 → 13（-38%）

创新点 3：混合文本检测与边界定位扩展能力 - [SEP] 边界标记机制：C2 检测率 +14.02% - Token 级边界检测器：96.69% Token 准确率，0-8 字符边界误差 - 双层级联推理架构

7. 常见答辩问题

Q1: 为什么选择 BERT 而不是 GPT/LLaMA？

答： 1. 任务匹配：文本分类是判别任务，BERT 的双向编码器天然适合理解全文语义；GPT 类单向解码器更擅长生成任务。 2. 效率：BERT-base 110M 参数，推理 7.8ms；LLaMA-7B 需要数秒且显存需求高 10 倍以上。 3. 部署成本：BERT 可在单张消费级 GPU 上部署，适合实际应用。 4. 性能对比：本实验中 BERT-BiGRU（104M）与 V11c（110M）准确率均超 98.6%，显著优于 DPCNN 等轻量模型。

Q2: Temperature Scaling 的作用是什么？

答： 1. 解决过度自信：神经网络普遍存在过度自信问题，校准前 ECE=0.0168，校准后降至 0.0034。 2. 不改变预测：只改变概率分布的平滑度，argmax 不变，准确率保持 98.69%。 3. 实际意义：当模型说"98% 是 AI"时，这个概率是可信的，可用于下游决策。

Q3: 四阶段数据治理的核心思想是什么？

答： 1. Data-Centric AI：固定模型、超参、损失函数，唯一变量是数据，验证数据质量的边际收益。 2. V11a（标签噪声清洗）：移除模板化样本和未知来源，减少标签噪声。 3. V11b（弱域增补）：在"正式书面语"和"LLaMA系列"两个弱域各增补300条，提升泛化能力。 4. V11c（长文边界修复）：补充256+字符AI样本，修复长文覆盖不足。 5. 效果：独立评估集错误数从21降至13（-38%）。

Q4: [SEP]标记为什么能提升混合文本检测？

答： 1. 明确边界：在人类文本和AI文本交界处插入[SEP]标记，为模型提供明确的分割信号。 2. C2场景：人类写开头、AI续写的情况下，没有[SEP]时模型难以感知风格切换。 3. 效果：C2检测率从79.82%提升至93.84%（+14.02个百分点）。

Q5: 如何保证评估的公平性？

答： 1. 三子集无泄露：训练集与评估集完全零重叠，评估集含训练未见的模型（GPT-5、Gemini-3等）。 2. 五类方法公平对比：在相同数据集、相同评估指标下对比 FastText/TextCNN/DPCNN/BERT-BiGRU/V11c。 3. 多维度鲁棒性测试：长度鲁棒性、格式鲁棒性、跨模型泛化能力。

Q6: 系统的实际应用价值是什么？

答： 1. 学术诚信：辅助教师鉴定学生作业是否使用AI生成。 2. 内容审核：平台可批量检测投稿内容的AI生成比例。 3. 边界定位：不仅能判断整篇是否AI生成，还能定位具体哪些段落是AI写的。 4. 生产级部署：已部署为API服务，127.4样本/秒，支持高并发请求。
