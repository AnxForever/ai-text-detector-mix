- 大语言模型(LLM)的快速发展（GPT、Claude、文心一言等）

## 第4章 方法设计（6-8页）

### 4.1 问题定义（0.5页）

```
给定文本 x，判断其标签 y ∈ {0, 1}
其中 0 表示人类撰写，1 表示AI生成
```

### 4.2 模型架构（2页）

**4.2.1 整体架构**

```
输入文本 → BERT编码器 → [CLS]表示 → 分类器 → 二分类输出
```

**4.2.2 BERT编码器**
- 输入表示：Token Embedding + Position Embedding + Segment Embedding
- 12层Transformer
- 输出：768维[CLS]向量

**4.2.3 分类头设计**
```python
classifier = nn.Sequential(
    nn.Linear(768, 768),
    nn.Tanh(),
    nn.Dropout(0.1),
    nn.Linear(768, 2)
)
```

- 图4-1：模型整体架构图
- 图4-2：分类头结构

### 4.3 训练策略（2页）

**4.3.1 损失函数**
- 交叉熵损失
- [可选] 长度加权损失

**4.3.2 优化器配置**
- AdamW优化器
- 学习率：2e-5
- 权重衰减：0.01
- 预热步数：500

**4.3.3 训练技巧**
- 动态Padding
- 梯度裁剪
- 早停策略

**公式**：
```
L = -1/N Σ[y_i log(p_i) + (1-y_i) log(1-p_i)]
```

### 4.4 对比学习增强（可选，如果实现了）（1.5页）

**4.4.1 动机**
- 学习更鲁棒的特征表示
- 提升跨域泛化能力

**4.4.2 监督对比损失**
```
L_con = -log(正样本相似度 / Σ所有样本相似度)
```

**4.4.3 双任务学习**
```
L_total = (1-α) × L_cls + α × L_con
```
