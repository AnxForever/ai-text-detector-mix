## 🔴 核心问题

### 1. 样本风格不均衡
**现象**: 模型对不同风格的AI文本识别能力差异巨大

**具体表现**:
- ✅ 对话式AI（"作为一个AI语言模型..."）→ 100%识别
- ✅ 流畅解释式AI → 85%识别
- ❌ 列表式AI（冒号、分号、条目）→ 3%识别
- ❌ 技术文档式AI（专业术语密集）→ 0.1%识别

**测试案例**:
```
案例1（误判）:
"常见表现：loss突然飙升、出现NaN；权重数值变得很大；训练过程极不稳定。"
→ 模型判断: Human (96.9%)
→ 实际: AI生成

案例2（正确）:
"作为一个AI语言模型，我可以为您提供以下建议。"
→ 模型判断: AI (100%)
→ 实际: AI生成
```

**推测原因**:
- 训练数据中对话式AI样本过多
- 缺少技术文档、列表式、学术论文风格的AI样本
- 模型过度拟合了"作为AI"、"我建议"等明显特征

### 2. 混合文本干扰
**现象**: combined_v2包含3.1%的[SEP]标记混合文本

**问题**:
- [SEP]标记是为边界检测设计的，但混入了分类训练集
- 混合文本的标签不明确（是标为Human还是AI？）
- 可能导致模型混淆纯AI文本的特征

**数据示例**:
```
"人类写的前半段[SEP]AI生成的后半段"
→ 标签: ? (不清楚如何标注)
```

### 3. 数据质量参差
**现象**: combined_v2虽然样本更多，但效果反而变差

**可能的质量问题**:
- 标注错误（人类文本被标为AI，或反之）
- 低质量样本（过短、无意义、格式错误）
- 数据泄露（训练集和测试集重复）
- 来源单一（可能都来自同一个AI模型）

**需要检查**:
- 是否有重复样本？
- 标注准确率如何？
- 不同来源的AI文本比例？

### 4. 文本长度分布不均
**统计数据**:
```
0-100字符:    11.9%
100-200字符:  26.1%
200-500字符:  26.5%
500-1000字符: 15.5%
1000-2000字符: 13.1%
2000+字符:     6.9%
```

**问题**:
- 短文本（<200字符）占38%，可能信息不足
- 长文本（>1000字符）仅20%，缺少复杂样本
- 中位数277字符，平均608字符，分布右偏

### 5. 标签分布略不平衡
```
Human: 48.0%
AI:    52.0%
```
虽然接近平衡，但AI样本略多，可能导致模型偏向判断为AI。

## 🎯 需要AI研究的问题

### 问题1: 如何增加样本多样性？
**背景**: 模型对列表式、技术文档式AI识别很差

**需要研究**:
1. 应该生成哪些风格的AI样本？
   - 技术文档（API文档、技术规范）
   - 学术论文（摘要、方法描述）
   - 列表式内容（步骤说明、要点总结）
   - 代码注释风格
   - 其他？

2. 每种风格应该生成多少样本？
   - 是否需要平衡各风格比例？
   - 还是根据实际应用场景分配？

3. 如何确保生成样本的质量？
   - 需要什么样的prompt？
   - 如何避免生成过于明显的AI特征？

### 问题2: 混合文本应该如何处理？
**背景**: 3.1%的样本包含[SEP]标记

**需要研究**:
1. 混合文本应该单独训练还是混入分类训练？
2. 如果混入，标签应该如何定义？
   - 标为"mixed"第三类？
   - 根据AI占比标为Human/AI？
   - 完全移除？

3. [SEP]标记是否影响模型学习？
   - 模型是否会过度依赖[SEP]？
   - 是否应该在预处理时移除？

### 问题3: 如何检测和清洗低质量样本？
**背景**: combined_v2效果差，可能存在噪声

**需要研究**:
1. 如何自动检测标注错误？
   - 使用现有模型预测，找出置信度低的样本？
   - 交叉验证？

2. 如何定义"低质量样本"？
   - 过短（<50字符）？
   - 无意义（乱码、重复）？
   - 格式异常？

3. 是否需要人工审核？
   - 哪些样本需要人工审核？
   - 审核标准是什么？

### 问题4: 训练策略如何优化？
**背景**: 第3轮训练验证集准确率下降（过拟合）

**需要研究**:
1. 超参数如何调整？
   - 学习率：当前2e-5，是否过高？
   - Dropout：当前0.1，是否过低？
   - 训练轮数：3轮是否过多？

2. 是否需要分阶段训练？
   - 先在高质量数据上预训练
   - 再在多样化数据上微调
   - 最后在难样本上精调

3. 如何防止过拟合？
   - 早停机制（patience设为多少？）
   - 数据增强（哪些方法有效？）
   - 正则化（L2、dropout、label smoothing？）

### 问题5: 如何构建更好的测试集？
**背景**: 需要全面评估模型泛化能力

**需要研究**:
1. 测试集应该包含哪些类型？
   - 不同风格的AI文本
   - 不同领域的文本
   - 不同AI模型生成的文本
   - 对抗样本

2. 如何确保测试集的代表性？
   - 覆盖所有可能的应用场景
   - 包含边界模糊的难样本

3. 评估指标除了准确率还应该看什么？
   - 各风格的F1-score
   - 混淆矩阵
   - 置信度分布
