# Core V2 数据集

> 创建时间: 2026-01-29

## 数据来源

1. **core_v1** - 原有训练数据 (58,563条)
2. **新生成AI数据** - 2026-01-29生成 (13,231条)
   - G (学术论文): 2,636条
   - H (社交媒体): 3,928条
   - I (创意写作): 2,438条
   - J (技术文档): 2,223条
   - K (口语化AI): 1,135条
   - L (有缺陷AI): 871条

| 指标 | 数量 |
|-----|------|
| 总记录数 | 71,794 |
| Human (label=0) | 27,181 (37.9%) |
| AI (label=1) | 44,613 (62.1%) |

## 数据拆分

| 集合 | 数量 | 比例 |
|-----|------|------|

## 文件列表

- `train.csv` - 训练数据
- `val.csv` - 验证数据
- `test.csv` - 测试数据
- `full_dataset.csv` - 完整数据
- `merge_log.json` - 合并日志

## 字段说明

| 字段 | 类型 | 说明 |
|-----|------|------|
| text | string | 文本内容 |
| label | int | 0=Human, 1=AI |
| category | string | 文本类别 |
| source | string | 数据来源 |
